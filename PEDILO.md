# Pedilo

SaaS gastronómico para restaurantes, pizzerías, cafeterías, hamburgueserías y negocios de comida.

## MVP

- Login
- Registro
- Crear negocio
- Categorías
- Productos
- Menú digital
- Pedidos
- Panel de administración

## Stack

Backend
- Django
- Django REST Framework

Frontend
- React
- Vite
- TailwindCSS

Base de datos
- PostgreSQL

Autenticación
- JWT

## Regla

Cada funcionalidad debe acercar a Pedilo a tener su primer cliente.
